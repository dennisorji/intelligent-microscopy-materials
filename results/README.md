# Results directory

This directory is reserved for lightweight release artifacts such as selected summary tables and publication figures derived from the notebooks.

Large raw images, dataset archives, model checkpoints, and temporary Colab outputs are intentionally not stored here. The authoritative computational record remains the five notebooks in `notebooks/`, while the public NFFA-EUROPE SEM dataset is obtained from its original B2SHARE source.

Additional release-ready figures or tables may be added before the first Zenodo archive and ChemRxiv preprint release.
